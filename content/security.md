---
title: "Security"
description: "How to report a security problem with this site or its published material."
---

This is a static site. It has no login, database, comments, analytics, advertising scripts, or form processor.

If a post accidentally exposes sensitive infrastructure information, credentials, a dangerous unpatched condition, or misleading security guidance, please report it privately rather than opening a public issue.

Contact: `security [at] zezelj [dot] org`

Please include the affected URL and enough detail to reproduce or locate the issue. Do not test against unrelated services on the domain.
